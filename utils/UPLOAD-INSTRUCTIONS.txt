================================================
ABOUT THE TRANSLATION QUALITY
================================================

MyMemory (default, free):
- Quality: Basic - good for short text, can be awkward for
  long content. Sometimes mis-translates Thai idioms.
- Limit: ~1000 words/day per IP
- Best for: Quick prototyping, testing the system

Claude AI (anthropic, paid - very affordable):
- Quality: Excellent. Preserves HTML, tone, technical terms.
  Handles Thai-to-English/Chinese/Japanese very well.
- Cost: ~$0.001-0.005 per article (Haiku model is cheap)
- Best for: Production-quality content
- Get API key: console.anthropic.com (free $5 credit on signup)

DeepL (paid):
- Quality: Excellent for European languages, good for
  Thai-English. Less polished for Asian languages.
- Cost: Free tier 500K chars/month; Pro for more
- Best for: If you already have a DeepL subscription

================================================
TROUBLESHOOTING
================================================

If "Translate Entire Website" button times out:
  - The route processes all posts sequentially. With 50+
    posts it may take 2-3 minutes. Wait or do smaller batches
    by editing posts individually first.
  - Plesk Node.js may have a request timeout - in Plesk 
    Node.js settings, check the timeout (300s recommended)

If Claude API gives 401 / 403:
  - Your API key is wrong or expired
  - Settings -> Anthropic API Key -> paste a fresh key
  - Make sure no extra whitespace before/after the key

If translations look weird with HTML showing:
  - That's the MyMemory provider mishandling HTML
  - Switch to Claude (much better at preserving HTML structure)

If only the homepage works but post pages still show Thai:
  - The post hasn't been translated yet - go to Translation
    Manager and click "Translate to X" 
  - Make sure VIEW source on the post page shows ?lang= in
    URL or site_lang cookie

If mobile topbar still dark blue:
  - public.ejs upload didn't land
  - View source: search "critical-overrides-v36" - if missing, 
    re-upload and restart Node

If main header ALSO hides on scroll (you only want topbar to hide):
  - The CSS sets .site-header to position:sticky which keeps
    it visible. If your old CSS overrides this, the new inline
    CSS should win because of !important
  - Check public.ejs uploaded fully
